# Integration Checklist

## Before merging Person 1

- [ ] Engine tests pass
- [ ] Contracts unchanged or explicitly coordinated
- [ ] Public facade documented
- [ ] Deterministic flagship output stable

## Before merging Person 2

- [ ] Copilot tests pass
- [ ] Frontend builds
- [ ] API payloads match contracts
- [ ] Approval remains human-gated

## Full-system gate

- [ ] Baseline loads
- [ ] Disruption triggers
- [ ] 5 candidates appear
- [ ] hard constraints reject invalid options
- [ ] network simulation runs
- [ ] stress tests run
- [ ] critic can change recommendation
- [ ] human approval required
- [ ] execution updates state
- [ ] verification compares before/after
- [ ] reassessment can trigger
- [ ] same input produces same decision
