# 4–6 Minute Judge Demo

## 1. Opening

“A flight can always be rerouted if we only care about that flight. The real question is what that reroute does to everybody else.”

## 2. Disruption

Show weather near BOM, capacity degradation, holding and sector stress.

## 3. Agent investigation

Show OBSERVE → DIAGNOSE → TOOL CALLS → CANDIDATES.

## 4. Aha moment

Show shortest candidate with strong immediate metrics but weak future survival. Then show critic failure and the resilient candidate with slightly worse target-flight cost but lower network ripple and higher survival.

## 5. Human approval

“AERIS can recommend. It cannot execute without the dispatcher.”

## 6. Verification

Show before/after target benefit, network ripple and constraint status.

End with:

“AERIS does not optimize one aircraft in isolation. It makes resilient decisions for the network around it.”
